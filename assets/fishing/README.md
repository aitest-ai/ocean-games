# 釣魚遊戲的圖檔（assets/fishing）

## 資料夾與檔名規則

```
assets/fishing/
  species/<學名小寫，用 - 連接>.png   魚和海龜的側面圖鑑圖（例：girella-punctata.png）
  junk/<英文物品名>.png               海洋垃圾（例：pet-bottle.png）
```

- 檔名就是資料庫（`data/fishing/`）裡每一筆的 `id`，資料檔的 `art.file` 欄位寫著完整路徑。
- 每一種**只要 1 張**。大小不同的個體由程式依體長縮放；水面下的魚影由程式用同一張圖的輪廓自動產生。
- 檔案放進來、重新整理頁面就會取代暫代圖，不用改程式。檔案不存在時，遊戲會用程式畫的暫代圖（瀏覽器主控台會看到一筆 404，這是正常的）。
- 背景請用單一純洋紅色 `#FF00FF`：程式會自動去背、裁掉空白。已經去背（透明背景）的 PNG 也可以。
- 魚頭請朝左；若朝右，把該魚資料檔的 `"facing": "left"` 改成 `"right"`。

完整的繪圖清單與規格見 [`docs/fishing-art-request.md`](../../docs/fishing-art-request.md)。
