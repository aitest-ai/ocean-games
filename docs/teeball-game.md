# 雨天樂樂棒決策練習場（第一版）

獨立入口 `/teeball/`，不更動既有棒球打擊遊戲或辨識器。適合老師示範後輪流操作；不是正式比賽裁判系統，也不模擬局數。

## 試玩

`npm run dev`，開啟 `http://localhost:5173/teeball/`。本專案為原生 ES modules 靜態網站，無編譯步驟。部署必須 HTTPS 才能使用鏡頭（localhost 例外）。本分支沒有部署 workflow。

- **打擊準備**：先按開始準備，等安全綠燈，再用空白鍵、觸控或空手小幅揮擊。球固定在打擊座上；不是投手來球的時機訓練。
- **跑壘／停壘、守備傳球**：依明確的跑者、球、接球隊友狀態選答案。觸控選答案後確認；方向鍵選擇，Enter 確認。原地操作，不實際衝刺。
- **鏡頭**：使用者主動開啟後，左右微傾選擇、回正再選下一格、雙手舉起確認。可隨時改用觸控或鍵盤。換人請重新校準。辨識異常暫停後須按繼續。
- **老師設定**：預設基礎題；取消「先練基礎題」才包含需確認地方賽制的接殺死球、不回頭線等題。17 題含打擊安全4、跑壘7、守備6。

## 規則與安全

依中華民國樂樂棒球協會[一般組規則](https://chba.org.tw/cmrule/)與[規則問答](https://chba.org.tw/judgeanaly/)設計；老師仍應確認校內規則。不要套用棒球的觸殺、接殺後再進壘、二三壘不可衝過或三出局換局。特殊戰術題會明列前提；不是宣稱任何情況都有唯一傳球答案。

不用實體棒、球；清空周圍約1.5公尺空間，一人操作，老師陪同。可坐姿；鏡頭站姿／光線適應仍需實機驗證。手機直式與橫式皆有排版，不強迫旋轉。單手／按鈕無障礙替代只是遊戲操作，不教成正式比賽單手握棒。

## 隱私與生命週期

無帳號、姓名、成績上傳、錄影、麥克風或持久成績儲存。鏡頭畫面在瀏覽器處理；會載入原專案的姿態辨識模型／程式，下載模型不等於上傳影像。切換分頁、離開或按關閉會停止鏡頭。尚未完成的權限／模型載入亦有取消清理，避免晚到的串流留存。關閉頁面清空分數。

## 驗證與已知範圍

`node --test tests/*.test.mjs` 與 `node --test packages/taikan-kit/test/*.test.mjs`。
新測試涵蓋題庫、選項評分、微傾復位／冷卻、打擊狀態、暫停取消、辨識狀態、鏡頭非同步取消與錯誤。
自動測試不能取代真實學生動作、不同手機 Safari／Chrome 的權限／辨識校準與教師驗收。本版跑壘為情境決策，不宣稱偵測實際踏步或跑步。

## 3D 世界升級

`src/teeball/scene.js` 直接使用原遊戲 `LandWorld` / `createBallpark` 的球場、草土材質、天空、看台、燈光與人物 `Figure` IK；不是 SVG 場地圖或另外降低精細度的替代場景。打擊沿用原遊戲揮棒關鍵姿勢，但改為固定球座，不使用投手。

- 實戰／全場／跟隨三種鏡頭；可點 3D 壘圈選擇傳球或跑壘目標，再確認執行。
- 打擊成功會播放揮棒、球飛行及打者安全放棒後跑一壘的教學動畫。
- 橘衣跑者、藍衣守備、綠色圈標示就位接球點、金圈標示選擇；正確跑壘與傳球選擇播放對應路徑。錯誤決策只解說，不播放成合法進壘／觸殺。
- 全場保留題目跑者起點與球持有人；跑者並非因作答等待就自動被判出局。教學動畫不以現實動作速度評分。
- 球場美術沿用原少棒 18.29m 壘距，不是樂樂棒規格丈量圖；球體為可讀性放大。拋物線與人物速度是教學示意，不宣稱碰撞物理、裁判時序或正式比賽模擬。
- 手機使用原場景 low tier，像素比上限 1.5；直式場景在上、操作在下，橫式並排。尚未取得真實手機 FPS 數據。
- WebGL 無法建立時顯示明確訊息，按鈕／文字仍可練習；這個降級模式不等於 3D 已驗收。

### 驗收範圍與待驗

新增自動測試包含世界座標／軌跡端點、17 情境動畫決策、死球不再傳殺、跑者位置與來源元件。原 root 與 toolkit tests 均需通過。

本次雲端 CUA 瀏覽器的 WebGL vendor/renderer 為 Disabled，連原有公開球場也無法建立 WebGL context。受保護的 Vercel 預覽要求登入，沒有降低保護或建立繞過憑證。因此尚未取得真正 GPU 渲染截圖，不能宣稱畫面品質、手機流暢度或實體鏡頭已通過驗收。請在已有權限的 WebGL 裝置開預覽或 localhost，檢查三視角、揮棒接觸、球／跑者／持球人位置、手機兩方向、暫停、鏡頭追蹤與換人。
