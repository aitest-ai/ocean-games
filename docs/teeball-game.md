# 雨天樂樂棒決策練習場（第一版）

獨立入口 `/teeball/`，不更動既有棒球打擊遊戲或辨識器。適合老師示範後輪流操作；不是正式比賽裁判系統，也不模擬局數。

## 試玩

`npm run dev`，開啟 `http://localhost:5173/teeball/`。本專案為原生 ES modules 靜態網站，無編譯步驟。部署必須 HTTPS 才能使用鏡頭（localhost 例外）。本分支沒有部署 workflow。

- **打擊準備**：先按開始準備，等安全綠燈，再用空白鍵、觸控或空手小幅揮擊。球固定在打擊座上；不是投手來球的時機訓練。
- **跑壘／停壘、守備傳球**：依明確的跑者、球、接球隊友狀態選答案。觸控選答案後確認；方向鍵選擇，Enter 確認。原地操作，不實際衝刺。
- **鏡頭**：使用者主動開啟後，左右微傾選擇、回正再選下一格、雙手舉起確認。可隨時改用觸控或鍵盤。換人請重新校準。辨識異常暫停後須按繼續。
- **老師設定**：預設基礎題；取消「先練基礎題」才包含需確認地方賽制的接殺死球、不回頭線等題。17 題含打擊安全4、跑壘7、守備6。

## 規則與安全

依中華民國樂樂棒球協會[一般組規則](https://chba.org.tw/cmrule/)與[規則問答](https://chba.org.tw/judgeanaly/)設計；老師仍應確認校內規則。不要套用棒球的觸殺、接殺後再進壘、二三壘不可衝過或三出局換局。特殊戰術題會明列前提；不是宣稱任何情況都有唯一傳球答案。

不用實體棒、球；清空周圍約1.5公尺空間，一人操作，老師陪同。可坐姿；鏡頭站姿／光線適應仍需實機驗證。手機直式與橫式皆有排版，不強迫旋轉。單手／按鈕無障礙替代只是遊戲操作，不教成正式比賽單手握棒。

## 隱私與生命週期

無帳號、姓名、成績上傳、錄影、麥克風或持久成績儲存。鏡頭畫面在瀏覽器處理；會載入原專案的姿態辨識模型／程式，下載模型不等於上傳影像。切換分頁、離開或按關閉會停止鏡頭。尚未完成的權限／模型載入亦有取消清理，避免晚到的串流留存。關閉頁面清空分數。
