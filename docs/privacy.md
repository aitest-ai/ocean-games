## 第一部分：公告文字（給使用者看）

### 一句話版本

> 鏡頭就像一面只看動作的鏡子：畫面只在您自己的裝置上分析，**不錄影、不儲存、不上傳**，我們看不到、也拿不到您的影像。

### 鏡頭畫面怎麼處理

1. **只有選擇「鏡頭」玩法時才會用到鏡頭。** 第一次使用時，瀏覽器會跳出視窗詢問是否允許使用鏡頭，您可以拒絕，改用鍵盤玩。
   - 如果上次選的是鏡頭玩法，下次打開遊戲時會**自動開啟鏡頭**（若瀏覽器記得您允許過，就不會再問一次）。想避免這樣，請在遊戲選單改成「鍵盤」再離開，或在瀏覽器設定中取消鏡頭權限。
2. **不使用麥克風。** 本平台只要求鏡頭權限，不要求麥克風權限。
3. **畫面只在您的裝置上分析。** 鏡頭的每一格畫面會交給裝置上的姿態辨識程式，算出身體關節（例如肩膀、手腕、膝蓋）的位置座標，算完就丟掉，下一格再重算。
4. **不錄影、不拍照、不儲存、不上傳。** 影像和關節座標都**不會**存到裝置上，也**不會**傳到我們或任何第三方的伺服器。
5. **遊戲畫面上看不到您的影像。** 遊戲右下角的「鏡頭看到的你」小窗只畫骨架線條，不顯示真實畫面。
6. **鏡頭前若有第二個人**，辨識程式也會短暫算出他的骨架（用來提醒「請只留一位玩家」），同樣算完即丟。仍建議鏡頭只拍到玩家本人。
7. **什麼時候關閉鏡頭**：關閉或離開遊戲頁面、或在選單改用鍵盤時，鏡頭就會關閉。遊戲暫停時鏡頭仍會開著（讓您可以舉手繼續）。瀏覽器或裝置通常會顯示鏡頭使用中的指示燈。

### 我們會存什麼

- **不需要註冊、不需要登入**，我們不知道玩家是誰。
- 只會在**您自己的瀏覽器**裡記住遊戲設定（難度、鏡頭或鍵盤、靈敏度、音效開關、坐著玩、減少晃動等），方便下次使用。這些設定不含姓名、影像或身體資料，也不會傳給我們。清除瀏覽器的網站資料就會刪除。
- 本平台**沒有**放廣告、**沒有**使用分析或追蹤程式、**沒有**設定 Cookie。

### 網路連線

- 打開網站時，您的瀏覽器會向我們的網站主機下載網頁、程式、姿態辨識模型（第一次約 15 MB，之後由瀏覽器快取）。和瀏覽任何網站一樣，網站主機服務商（目前為 Vercel）會依其政策自動記錄連線紀錄，例如 IP 位址、時間、瀏覽器類型、讀取了哪些檔案。這些紀錄不含鏡頭畫面。
- 如果從我們的網站下載姿態辨識模型失敗，程式會**改從備用網站下載同一份模型**（jsdelivr.net、storage.googleapis.com，由 Google 等公司營運）。此時這些網站同樣會看到您的 IP 位址等連線資訊，但**不會**收到任何鏡頭畫面。
- 說明文件頁面會從 jsdelivr.net 下載排版程式。

### 老師用的「測試頁」

測試頁（輸入層測試工具）是給老師或技術人員調整鏡頭用的，和遊戲不同：

- 測試頁會在**您自己的螢幕上**半透明顯示鏡頭畫面，方便對位。
- 測試頁有「錄製骨架」按鈕：按下後會把**關節座標數字**（不含影像）存成檔案，**下載到您自己的裝置**，不會上傳。這種檔案有可能看得出一個人的身形與動作習慣，請妥善保管，用完刪除，不要在未經同意下錄製學生。

### 給學校與家長的建議

- 讓鏡頭只拍到玩家本人，背景避開其他同學。
- 若學校要拍攝上課情形，請依學校肖像權規定另外處理，與本平台無關。
- 在公用平板上使用後，可以在瀏覽器設定中取消鏡頭權限。

### 建議的程式調整（之後由負責共用外殼的 session 處理，本輪不改程式）

1. **鏡頭改成「每次都要按一下才開」**：目前上次選鏡頭，下次一打開頁面就自動開鏡頭。給兒童使用的產品，建議每次都由使用者按「開啟鏡頭」才啟動，並在畫面明顯處顯示「鏡頭使用中」。這也比較符合「使用者知情」的原則。
2. **商用版隱藏測試頁**：測試頁會顯示真實畫面並能下載骨架檔，建議不要放在一般使用者看得到的首頁，改成老師或管理者才看得到的入口。
3. **暫停超過一段時間（例如 2 分鐘）自動關閉鏡頭**，回來時再按一下開啟。
4. **把備援下載網站改成可以關閉**（例如學校版設定「只從本站下載」），讓學校可以宣稱「除了本站之外不連任何網站」。
5. 首頁頁尾加上「隱私說明」連結。

### 本平台是否「蒐集個人資料」？（**需律師確認**）

我的整理（非法律意見）：

- 依台灣《個人資料保護法》，個人資料包括「特徵」與「其他得以直接或間接方式識別該個人之資料」，臉部影像屬於個人資料。
- 但本平台的營運者**從頭到尾拿不到**影像或骨架資料：處理只發生在使用者自己的裝置、由使用者自己的瀏覽器執行，也不會保存。這種情況下，營運者可能不算「蒐集、處理、利用」個資的主體。
- 不過仍有幾點要請律師判斷：
  1. 「在使用者裝置上執行我們提供的程式來分析影像」是否仍被視為我們在「處理」個資。
  2. 網站主機記錄的 IP 位址是否構成我們蒐集個資（多數見解認為 IP 可能屬於「間接識別」的資料）。
  3. 若之後加入帳號、成績紀錄、老師後台、使用統計，就一定會蒐集個資，屆時需要依法告知、取得同意（兒童需家長同意），並建立安全維護措施。
