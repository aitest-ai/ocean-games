### 換成什麼

**全部改成程式即時合成**（`src/audio/synth.js`），沒有用任何外部錄音，所以不需要標示、也沒有授權風險。

- **為什麼不找 CC0 錄音**：本輪的工作環境連不到 Wikimedia、Freesound 等素材網站，無法親自下載並核對授權頁。我判斷「沒親眼核對過授權的錄音」風險比「合成音」高；而這個引擎原本的海浪、風聲就是合成的，合成雨雷聲和整體風格一致。
- **雨聲**：模擬一場大雨從稍遠處聽到的聲音——每秒約 2,600 顆遠處雨滴的細小撞擊聲、每秒約 40 顆近處雨滴的「滴答」顆粒感，再加上一層柔和的底噪；頻率範圍調成和原錄音一樣（大部分能量在 250～4,000 赫茲）。做成 8 秒無縫循環。
- **雷聲**：依照科學文獻的方法（Ribner & Roy 1982）：先用隨機路徑畫出一道彎彎曲曲的閃電（從地面往上到雲底，再往雲裡橫向延伸幾公里），閃電每一小段都會發出一個「啪」的震波，依距離延遲抵達耳朵；剛好側對著我們的直段會疊成響亮的「轟」，整條閃電遠近不同就形成「轟隆隆」的拖尾；距離越遠，高音被空氣吸收得越多，只剩低沉的隆隆聲。近雷（約 350 公尺）多了清脆的撕裂聲；遠雷（2.6 公里、4.2 公里）比較低沉。
- **保留**：`thunder_a`～`thunder_d` 四段遠雷錄音是 **CC BY 3.0**，符合標準，而且是真實錄音，保留使用並標示作者。

### 怎麼確認「聽起來仍自然」

我沒辦法用耳朵聽，所以用數據和原錄音逐項比對（都在真正的瀏覽器 Chromium 中跑過整個音效引擎）：

| 比對項目 | 原錄音 | 合成音 | 說明 |
|---|---|---|---|
| 雨聲：頻率重心 | 1,148 Hz | 約 1,290 Hz | 音色亮度接近 |
| 雨聲：各頻段能量分布（500–1k / 1k–2k / 2k–4k Hz） | 39% / 27% / 11% | 31% / 38% / 16% | 形狀接近，合成的略亮一點 |
| 雨聲：遊戲混音中的音量 | −20.1 dB | −20.5 dB | 差 0.4 dB，聽不出差別 |
| 雨聲：循環接縫 | （原錄音 30 秒循環） | 接縫處沒有爆音，前後音量變化在正常起伏範圍內 | 用「等功率交叉淡化」 |
| 近雷：遊戲混音中音量（打雷後 0–3 秒 / 3–10 秒） | −16.5 / −21.2 dB | −16.6 / −17.8 dB | 開頭幾乎一樣；中段拖尾稍長 |
| 近雷：開頭 2 秒的中高頻（500–4000 Hz）比例 | 約 12% | 約 15% | 都有清脆的「撕裂」感 |
| 近雷：峰值與平均音量差（越大越「有爆發力」） | 22.6 dB | 22.9 dB | 一樣 |
| 遠雷：遊戲混音中音量（0–3 秒） | −22.1 dB | −21.8 dB | 一樣 |
| 遠雷：頻率重心 | 160～250 Hz | 100～130 Hz | 合成的稍微更低沉一些 |
| 效能 | 下載約 1.5 MB 的 MP3 | 開聲音時合成雨聲約 0.25 秒；雷聲只在第一次打雷時才合成 | 網站少了 1.5 MB；三款遊戲沒有閃電，不會花時間合成雷聲 |

## 四、新增素材時的登記格式

每新增一個第三方東西（或自製但可能被誤會是外部的素材），請在第二節表格加一列，並同步更新 [第三方授權頁](../licenses.html)。

**登記欄位**（照抄這個範本）：

```
| 編號 | 項目名稱 | 檔案位置 | 來源（網址＋作者） | 授權（名稱＋版本＋條款連結） | 商用 ✅/⚠️/❌ | 需標示？ | 備註（修改了什麼、哪個遊戲用到、核對日期） |
```

**新增前的檢查清單**：

1. [ ] 打開原始授權頁面，**親眼看到**授權名稱（不要只相信搜尋結果或別人的轉貼）。
2. [ ] 授權在第一節「可以用」那一欄裡；有 NC、SA、ND 一律不用。
3. [ ] 把授權頁另存成 PDF 或截圖，放到內部雲端硬碟（網站上的授權有可能被作者改掉，留證據）。
4. [ ] 記下作者名稱、原始網址、授權版本，以及我們做了什麼修改（剪輯、調色、轉檔……）。
5. [ ] AI 生成的素材：記下用的工具、方案（有些免費方案不允許商用）、日期，並在備註寫「AI 生成」。
6. [ ] 同時更新本檔與 `licenses.html`；音效另外更新 `assets/audio/CREDITS.md`。
