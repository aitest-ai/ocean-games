# 釣魚遊戲：請 GPT 畫的圖檔清單

> 這份清單是從魚類資料庫（`data/fishing/`）自動整理出來的，檔名、辨識特徵都和遊戲裡用的一致。
> 共 **15 張**：魚與海龜 10 張（每種 1 張側面圖鑑圖）、海洋垃圾 5 張。

## 一、為什麼只要這麼少張

- **每一種只要 1 張側面圖。** 遊戲會自動用同一張圖做出三種用途：
  1. 圖鑑卡與冰箱裡的圖；
  2. **水面下的魚影**：程式把圖的輪廓壓暗、模糊、讓身體左右擺動（所以魚影和圖鑑圖的形狀一定一致）；
  3. 釣上來那一瞬間跳出水面的魚。
- **大魚、小魚不用另外畫。** 程式依每一隻的體長自動縮放。
- **卡片上的所有文字、數字、圖表都由程式排版**，圖片裡**不要有任何文字**。

## 二、共同規格（每一張都一樣）

| 項目 | 要求 |
|---|---|
| 背景 | **單一純洋紅色 `#FF00FF`**（整片同一個顏色，不要漸層、不要陰影、不要地面） |
| 主體 | 只有一隻（一個物品），**完整入鏡**，四周留約 5% 空白，不要被裁切 |
| 方向 | 魚和海龜一律**頭朝左**、正側面（像圖鑑標本照的角度），不要斜角、不要俯視 |
| 風格 | **偏寫實的圖鑑插畫**（科學繪圖／水彩寫實皆可），顏色、斑紋、鰭的形狀要正確 |
| 光線 | 柔和的均勻光，從左上方來；主體身上不要有強烈反光或投影到背景 |
| 禁止 | **任何文字、數字、比例尺、標籤、浮水印、簽名、邊框**；不要畫水、石頭、魚鉤、釣線、手 |
| 顏色注意 | 主體身上避免出現接近洋紅的粉紫色（去背時會被誤刪） |
| 檔案 | PNG；魚和海龜 1536 × 1024（橫式），垃圾 1024 × 1024（正方形） |

### 可以直接貼給 GPT 的提示詞範本

```
請畫一張偏寫實的魚類圖鑑插畫：{中文名}（學名 {學名}）成魚的正側面，頭朝左，
身體水平、所有鰭自然張開，完整入鏡、四周留白。
辨識特徵：{把下面清單的辨識特徵貼上}。
背景是單一純洋紅色 #FF00FF，沒有漸層、沒有陰影。
畫面中不要有任何文字、數字、標籤、比例尺、浮水印或邊框，也不要畫水、石頭或釣具。
尺寸 1536×1024。
```

- **檔名**：`assets/fishing/species/girella-punctata.png`
- **尺寸**：1536 × 1024 像素（橫式），PNG
- **畫什麼**：一尾成魚的正側面（**頭朝左**），身體水平、鰭自然張開（背鰭、臀鰭、腹鰭、尾鰭都看得到）；體型參考：常見 30～40 公分（全長）的個體

## 五、圖畫好之後怎麼放進遊戲

1. 把檔案照上面的檔名放進 `assets/fishing/species/` 或 `assets/fishing/junk/`（檔名全部小寫英文）。
2. 重新整理遊戲頁面，暫代圖就會被換掉，不用改任何程式。程式會自動：去掉洋紅背景、裁掉多餘空白、依體長縮放、產生魚影。
3. 如果某張圖畫成頭朝右，可以在該魚的資料檔（`data/fishing/species/<檔名>.json`）把 `"facing": "left"` 改成 `"right"`，程式會自動翻轉。
4. 請用遊戲裡的「🧊 冰箱與圖鑑」看每張卡片，確認顏色、去背邊緣是否乾淨。

## 六、請核對的地方

- 以上辨識特徵是依一般形態知識整理（查證狀態多為「部分查證」），**請對照有授權的照片**（例如 iNaturalist 上標示 CC BY 或 CC0 的照片）或請懂魚的人看過再定稿。
- 「黑毛」常和細鱗的近親 *Girella leonina* 混淆；「白毛」對應到哪一種魚也還要請在地釣友確認（目前用天竺舵魚）。
- 「石狗公」是好幾種鮋科魚的通稱，這張請畫褐菖鮋。
- GPT 產生的圖片：請確認您使用的服務條款允許商業使用，並在素材清單（`assets/fishing/README.md`）登錄「自製（AI 生成）」與產生日期。
